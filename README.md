# MIPYME Contable

Plataforma web de gestión contable para PYMES y emprendedores.

## 🚀 Características

- Asesoría contable especializada
- Herramienta contable en línea
- Cursos interactivos
- Facturación electrónica
- Gestión de nómina

## 📁 Estructura del Proyecto

- `index.html` - Página de inicio
- `asesorias.html` - Servicios de asesoría
- `herramienta.html` - Herramienta contable
- `cursos.html` - Cursos y recursos
- `contacto.html` - Información de contacto
